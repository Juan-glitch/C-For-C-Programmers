# C++ CMake Probe Template

Use this for small C++ experiments before integrating them into production code.

Commands:

```bash
python3 dev_tools/lab_cli.py build <name>
python3 dev_tools/lab_cli.py test <name>
python3 dev_tools/lab_cli.py run <name>
python3 dev_tools/lab_cli.py launch <name> --vscode --apply
```
